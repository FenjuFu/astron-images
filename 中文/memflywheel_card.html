科大讯飞 开源 Agent 记忆层

一图上手 MemFlywheel

"Turn every Agent run into a smarter start for the next one."
为 AI Agent 打造的文件原生长期记忆层：记忆存成可检查、可 diff 的 Markdown 文件，让 Agent 每跑一次，下一次都更聪明。
核心特性
📄 文件原生存储
Markdown 记忆 + 源码追踪 + 学习技能，全部可检查、可版本对比
🔍 渐进式回忆
前置回忆 + 分层阅读，从索引线索逐层深入到证据
🌙 运行后学习
轮次结束自动提取记忆，空闲时"做梦"巩固与修复
🔌 Harness 原生集成
开箱支持 Pi / Hermes / OpenCode / OpenClaw
记忆飞轮怎么转
01
预回忆
从 MEMORY.md 取索引线索
➜
02
渐进读取
记忆体→源追踪→技能
➜
03

持久化本轮新记忆

梦幻巩固与修复
↻ 重复的工作沉淀为可复用「学习技能」，飞轮越转越快
30 秒上手（以 Pi 为例）

$ pi install npm:@iflytekopensource/adapters
