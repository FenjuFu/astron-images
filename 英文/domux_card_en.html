⚡What It Does: Natural Language → Structured Command
IN"Turn on the living room light"
↓ parsed into the 7-field pipe format
OUTturnOn|Light|*|*|*|Living Room|*
Fields: action | device | attribute | value | unit | room | floor · compound commands auto-split into rows · any device name via semantics, no whitelist

🏠 What It Controls

  • Lights: brightness / color / color temp / modes
  • AC: temperature / mode / fan speed
  • Curtains: open / close / position
  • Scenes: activate / deactivate in one shot

🔧 Training & Serving

  • SFT + GRPO RL with custom reward plugins
  • Training code + 4,057-sample test set open
  • vLLM / SGLang, OpenAI-compatible API
  • Beats much larger models on accuracy
